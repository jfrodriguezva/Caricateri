# Caricateri: Origen Uapeani

Aventura de acción en 3D por el México de hacia 1500, con Uapeani joven. Por ahora es un mundo abierto para explorar.

**Jugar:** https://jfrodriguezva.github.io/Caricateri/

La primera carga baja unos 130 MB; las siguientes abren desde el almacenamiento del navegador.

## Controles
| Acción | Teclado y ratón | Mando |
|---|---|---|
| Mover / correr | WASD / Shift | Palanca izquierda / L3 |
| Cámara | Ratón (clic para capturarlo) o flechas | Palanca derecha |
| Acción / rodar | Espacio | A |
| Atacar · escudo · fijar · hacha | J · K · Q · E | X · RB · LB · Y |
| Mapa y viaje rápido (clic en el mapa) | M | Select |
| Cambiar de época: Caricateri (hacia 1475) o Uapeani (hacia 1505), en el mismo lugar | T | R3 |
| Explorar volando (Espacio sube, C baja, Shift rápido) y aterrizar | F | Cruceta arriba |

En el celular hay controles en pantalla.
